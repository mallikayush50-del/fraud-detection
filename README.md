# Fraud Detection using Machine Learning

## Project Overview

This project is a machine learning based fraud detection system developed using Python and Jupyter Notebook.

The project predicts whether a financial transaction is fraudulent or not.

## Features

- Machine learning based fraud detection
- Jupyter Notebook for model development
- Streamlit web application
- Transaction prediction

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Joblib
- Streamlit
- Jupyter Notebook

## Project Files

- `Fraud_detection.ipynb` - Machine learning development notebook
- `app.py` - Streamlit prediction application
- `fraud_detection_pipeline.pkl` - Trained machine learning pipeline
- `AIML Dataset.csv` - Dataset
- `requirements.txt` - Python dependencies

## Input Features

The application accepts:

- Transaction Type
- Amount
- Old Balance of Sender
- New Balance of Sender
- Old Balance of Receiver
- New Balance of Receiver
